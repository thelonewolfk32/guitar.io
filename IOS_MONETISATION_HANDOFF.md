# Apple monetisation handoff

Superseded by IOS_REACT_NATIVE_HANDOFF.md and MONETISATION.md.

Current model: no ads; cloud and basic Learn free; five saved entries / 150 MiB Free, unlimited song count / 1 GiB Premium, 30 MiB per new file. Premium is AUD 5/month or AUD 50/year and adds automation, synchronised YouTube and early access. Apple purchases use RevenueCat/StoreKit under the same account; desktop uses Stripe.
