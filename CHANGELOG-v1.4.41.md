# Guitar.io 1.4.41

Playback speed is now locked to 5% increments. Percentage entry, the slider and BPM entry resolve to the same nearest supported speed; the displayed BPM reflects the applied value. Section speed controls also use 5% increments, and combined whole-song/section rates snap before playback. Native YouTube requests follow the same grid.

Imported GP tempo data and recording sync points retain their original precision. Existing libraries and the V1.4.4 updater remain unchanged.

Windows x64 and Apple Silicon Mac builds are published through GitHub so V1.4.4 users can test automatic or one-click updating. Open Help (?) → version number → Check for updates, or enable Auto-updater and restart at the library.
