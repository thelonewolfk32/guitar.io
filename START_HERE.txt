Guitar.io V1.4.41

Windows: extract the full ZIP, then open Guitar.io.exe.
Apple Silicon Mac: extract the Mac ZIP, run Prepare and open Guitar.io.command once, then open Guitar.io.app.

Update BOTH paired computers, then use Device sync > Sync now.
Missing metadata repair resumes the existing checkpoint without resetting the library.
Device sync > Show diagnostics (OFF by default) shows failures and exports a report.

Help (?) > version number opens Updates.
Check for updates downloads, verifies, installs and restarts when an update exists.
Auto-updater OFF/ON controls launch downloads and installation while the library is idle.
Close editors and return to the library before installing.
Mac updates attempt local signing and offer an approval command if needed.
V1.4.3 users must install V1.4.4 once manually to obtain the new installer.
The personal library remains in separate app data.
Read GITHUB_RELEASES.md for publishing source and future versions.
No iOS build is included.
