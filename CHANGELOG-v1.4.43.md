# Guitar.io 1.4.43

Version-only reissue of V1.4.42 to test automatic updating on Windows and Apple Silicon Mac. The app and package versions are now 1.4.43. Features, playback, syncing, storage and updater implementation are unchanged.

With V1.4.42 installed, enable Auto-updater under Help (?) → version number, restart Guitar.io, and leave it on the library screen. The app should download this release, replace itself and reopen as V1.4.43. Manual Check for updates uses the same installer.
